# MoneyFlow

Responsive personal finance frontend built with React, TypeScript, Vite, React Router, Tailwind CSS, Recharts, and Lucide icons.

## Run locally

```sh
npm install
npm run dev
```

## Screens

- Marketing landing page
- Dashboard with an honest first-use state and transaction-derived totals
- Transaction search and category/type filters
- Budget and goal setup with progress derived from entered activity
- Reports, insights, MoneyFlow Coach, and settings views

The frontend currently keeps entered data in React state for the current session. It is ready to connect to the planned Express API; persistence, authentication, and server-side financial calculations are not wired up yet.
